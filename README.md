One funny line about an AI agent that automated its owner's job and then applied for that same job with a better resume. A small Python script reads the line from entry.txt, checks it is a single line of 1-140 characters, and writes it to /output/entry.txt — no network, no randomness, the same line every time.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
